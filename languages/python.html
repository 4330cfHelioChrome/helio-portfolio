Simple If-Else Check

A basic script checking user age eligibility.

age = 18
if age >= 18:
    print("Access Granted")
else:
    print("Access Denied")

For Loop Iteration

Iterating through a list of string elements.

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(f"I love eating {fruit}")

Basic Function with Return

A simple calculator function for addition.

def add_numbers(a, b):
    return a + b

result = add_numbers(5, 3)
print(result)  # Output: 8
